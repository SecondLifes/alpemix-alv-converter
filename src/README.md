# src/

This is the default working/output root for this project. Unless the user
names a different location, AI-generated deliverables (scripts, modules,
whatever was actually asked for) go here.

This is **not**:
- `examples/` — curated reference material demonstrating good practice,
  hand-maintained, not a scratch or output area.
- `docs/` — documentation, not code.

See `AGENTS.md`'s "Working Directory" section for the full rule, and
"Layer Structure (Architecture)" (or its stack-specific replacement) for how
this particular project organizes what goes inside `src/`.
